# 能力、原理、差异与迁移价值

## 最容易理解的区别

两个仓库像两个人整理的 AI 产品说明书文件夹：共同用途是阅读、比较与研究；差别是收集的产品、版本、模式和附件不同。两个来源可以同时使用，尚未做内容级去重，因此没有准确的重合率。

## 本次库的能力与原理

- 系统提示词：角色、沟通、任务边界、完成标准。
- 工具说明：名称、参数、何时使用及约束。接口声明不是实现代码。
- 工作流程：任务分解、阶段产物、读取反馈并继续执行。
- 模式与配置快照：观察产品的工作方式，但不能仅凭文件名证明正在使用。

资料通过目录与 Git 归档。提示词进入模型上下文影响行动选择；实际搜索、读取、执行由工具与运行程序完成。两个库均不提供完整原产品的一键复现。

## 双库比较依据

asgeirtj 的目录包括厂商产品、历史和官方公开样本归档、功能指令、子 Agent、Skills 及部分脚本与组件。x1xhlol 的目录提供 Manus、Kiro、Cursor、Lovable、Replit、v0 等产品的提示词和工具接口，也包含厂商产品与开源项目样本。

因此“偏厂商产品档案 / 偏应用流程案例”只是收录倾向。不能认为前者只有聊天指令、后者只有工具，也不能凭文件数比较实际能力。
