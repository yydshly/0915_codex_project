# 004 · AI 工具资料库：收集、分析与理解报告

收集 Manus、Kiro、Cursor、Lovable 等 AI 工具的提示词、工具说明与配置资料，供研究者解析、分析并整理成产品理解报告；对我们的实际价值仍需后续研究与验证。

## 我们的当前理解

这个库是理解市场上已有 AI 产品的资料来源。仓库负责收集与归档，研究者依据资料解析信息、分析理解，最后汇集出相关报告。仓库本身不自动完成产品分析，也不直接提供这些产品的运行能力。

与 asgeirtj/system_prompts_leaks 的基础用途相近：本库的应用与 Agent 流程案例较突出，另一个库的厂商产品版本、功能与模式资料较突出，两边有交叉。

**当前评价：已经完成初步理解与展示；对我们的具体用途、可迁移方法及真实效果，需要后续研究验证。**

## 网页内容

1. **双库对照：** 两个资料文件夹说明共同能力和收录倾向，按研究问题切换选用建议。
2. **收录能力：** 角色规则、工具接口、任务流程及当前快照统计。
3. **交互案例：** Manus 五步反馈循环、Kiro 四步阶段流程、Cursor 四步工具选择示意。支持选择步骤、前后切换与重置。
4. **价值意义：** 复用通用原理，增加产品案例，将规则迁移到可控实验中。
5. **研究依据：** 固定版本链接、JSON 检查结果、可下载证据和验证边界。

案例使用原创预设教学数据，不调用模型、不执行上游工具，不代表原产品实测成绩。

## 本地运行与构建

原生 HTML、CSS、JavaScript，无外部依赖、外部字体或远程脚本。直接打开 app/index.html 也能使用核心交互。

在总仓库根目录运行：

```sh
python scripts/build_web.py
python -m http.server 8774 --bind 127.0.0.1 --directory web
```

打开 `http://127.0.0.1:8774/004-ai-tool-prompts/`。

`app/` 为维护源，总仓库构建汇总至 `web/004-ai-tool-prompts/`。远端发布采用仓库已有的 GitHub Pages 工作流，主分支提交后自动检查并部署。用户于 2026-09-15 授权将本项目提交 GitHub 并发布，封面沿用已确认的 research-guide.png。
