01 / THE THINKING BEHIND THE REPORT

梳理专业报告格式，
用约束实现展示效果。

它的本质是从专业报告等资料中，梳理样式、字体、图片与图表编排、表格、分页等格式信息，再整理成 AI 可执行的约束，通过组件和制作流程实现相应效果。

我们的理解：主要价值是专业资料与制作经验的整理、约束和复用。它也整理了章节组织、数据引用与结论表达，但没有提供新的底层研究算法；对已有成熟报告流程的人，新增价值相对有限。

02 / WHERE RULES COME FROM

“硬规则”不都来自统计。

证据 → 判断 → 约束
样本统计

先测量实际报告

作者从候选中采集 PDF，提取页面、字体、文字颜色和书签信息；再观察分布与中位数。

机构 PDF → 解剖数据 → 经验基线

可以复算数量，但不能直接证明某种设计效果最好。

编辑判断

再决定读者需要什么

阅读摘要、研究图题与章节安排，把“有用的表达方式”写成选型规则和写作要求。

阅读样本 → 理解用途 → 结构规范

例如一页一结论、机制分析、附录体量上限。

工程经验

把失败变成防护

根据中文小字、内容粘连、图表裁切与目录错页等问题，将修复方式固化到组件和检查器。

真实故障 → 找出根因 → 代码约束

具体阈值是项目默认，需要按版式与场景调整。

研究结论

核心是专业报告格式与制作经验的工程化整理：从资料中梳理样式、字体、图片、图表、表格和分页规则，通过约束实现展示效果。内容组织规范是补充；技术增量有限，研究洞见和证据有效性仍依赖使用者。
