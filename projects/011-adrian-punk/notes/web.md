# 总结网页与发布说明

[返回项目入口](../README.md)

## 当前页面理解

以人物介绍、经历介绍、文章介绍、产品介绍、联系方式构成个人主页，分别用唱片、放映机、轨道星球、磁带与电视机、书信形成故事效果。先根据真实材料构造自己的故事，再用物件关联、交互与统一风格引导访客阅读。

- 主引导图使用最开始分析时的五个页面汇总图 `assets/overview.png`，原图保持不变。项目封面、README 与网页正文均使用该图，正文直接展示。
- 网页依次说明：核心理解与引导图、五类内容映射、故事承接机制、四步个人主页计划、补充产品研究。
- `app/openings.html` 保留点亮工作台、拆信与连接星图三个可重播示例，文案不代表用户真实经历。
- 原先以“研究成果包”为主的推荐路线已调整为“整理真实材料 → 构造人物主线 → 映射物件 → 实现个人主页”，与本次确认的理解一致。

## 构建与部署

沿用仓库现有 GitHub Pages 流程：

```sh
python scripts/projects.py check
python scripts/build_web.py
python scripts/check_web.py
```
