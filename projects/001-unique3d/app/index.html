01

输入决定起点

尽量正面、主体完整、遮挡少。被裁掉的最长方向可能使比例失真；模型无法从缺失的观测中确认真实背面。

学到的知识

为什么需要预训练模型？

同一张正面图，可能对应很多种背面。几何公式不能唯一确定被遮住的结构。多视图扩散模型利用训练中学到的物体规律，生成合理的其他角度；法线模型提供表面朝向。

这里使用的是经过微调的图像扩散模型，不是聊天式语言模型。权重是运行前准备的工具，物体图片才是每次任务的输入。

当前物体的优化

为什么还需要 ISOMER？

几个生成视角未必完全一致。算法先建立初始网格，再通过可微渲染比较轮廓和法线，调整顶点，拆分或合并网格边。ExplicitTarget 综合可见视角的信息，减少冲突。

“优化这个物体”与“训练通用大模型”是两件事。生成参考图之后，重建阶段主要更新当前网格。

记住这一句

模型如果把背面猜错了，算法可能把这个错误的背面也做成立体。

01

单图的盲区

背面和遮挡区域依赖推测。四个水平视角不能完整覆盖顶部、底部与复杂凹陷。

02

输入的姿态

完整、清晰、少遮挡的正面图更适合。复杂姿势和裁切可能破坏比例与结构。

03

生产的距离

网格可导出不等于可直接用于制造或动画。真实尺寸、壁厚、拓扑与材质需要另行检查。

06 / KEEP THE DISTINCTIONS

几个值得保留的判断

是算法，还是借助大模型？

两者配合。微调后的图像扩散模型生成参考视图和法线，几何算法把这些信息落实为网格。算法不只是“把图片拼起来”。

运行时需要重新训练大模型吗？

常规推理加载已有权重，随后对当前物体进行网格优化。作者的训练与使用者的推理是不同阶段。仓库 README 的训练代码发布项仍未勾选，不能假定已提供完整训练流程。

网页能直接在浏览器生成吗？

本页是静态研究网页，不包含生成后端。Unique3D 原版使用 Python / PyTorch、CUDA、PyTorch3D 和 nvdiffrast 等组件；Gradio 是操作界面，计算在后端 GPU 上完成。

能直接拿来打印、做角色动画吗？

导出网格是起点。打印需要检查封闭性、壁厚、尺寸和支撑；动画需要适当拓扑、骨骼与权重。现有流程没有自动完成这些步骤。

下一步做领域训练合适吗？

先用现有权重做目标类别测试，再整理失败模式。领域训练需要合法数据、训练代码与算力；通常先完成资产后处理与质量检查更容易获得实际价值。
