# 网页说明与验证

## 页面目标

详细讲清框架原理，尤其是从源码发现问题的过程，以及不同程度的定制需要改什么。原生 HTML / CSS / JavaScript 实现，保持仓库现有 GitHub Pages 子路径结构。

页面入口：[`app/index.html`](../app/index.html)。发布构建目录：`web/008-defending-code-harness/`。

## 本地查看

在研究总仓库根目录运行：

```sh
python scripts/build_web.py
python scripts/check_web.py
python -m http.server 8808 --bind 127.0.0.1 --directory web
```

然后访问 [本地预览](http://127.0.0.1:8808/008-defending-code-harness/)。地址仅在本机服务运行时有效。独立打开源 HTML 也可阅读，返回总索引应在汇总构建后的页面使用。

当前没有新增公开部署；`demo_url` 保持为空。
